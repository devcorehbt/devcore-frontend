# Política de Segurança

## Reportando uma vulnerabilidade

A segurança do DevCore Frontend é levada a sério. Se você encontrar uma vulnerabilidade,
**não abra uma issue pública**.

Em vez disso, use o canal privado de [Security Advisories do GitHub](https://github.com/devcorehbt/devcore-frontend/security/advisories/new)
ou entre em contato diretamente com a equipe DevCore.

Inclua, se possível:

- Descrição da vulnerabilidade e impacto potencial
- Passos para reproduzir
- Versão/commit afetado

Faremos o possível para responder em até **5 dias úteis**.

## Versões suportadas

Apenas a branch `main` recebe correções de segurança.
